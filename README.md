# The Venomous Abyss — Raid Guide

Fanovský boss guide na všech 8 bossů raidu **The Venomous Abyss** (WoW patch 12.1, *Curse of Ula'tek*, Midnight Season 2): Nek'zali the Soulcoiler, Entombed Sentinels, The Lost Explorers, Vashnik the Malignant, Sszorak, The Twin Fangs, The Coiled Altar a Ula'Tek.

Sestaveno z veřejně dostupných community zdrojů (Wowhead, Icy Veins, ExpCarry, Warcraft Wiki). Nespojeno s Blizzard Entertainment.

Živá verze: `https://<username>.github.io/<repo>/`

Každá stránka obsahuje: přehled mechanik, schopnosti podle fáze/cíle, časovou osu fightu, tipy podle role (tank/healer/DPS), rozdíly mezi Normal/Heroic/Mythic a kvíz na ověření znalostí. Mezi stránkami se dá překlikat přes lištu nahoře.
